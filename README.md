# Umar Kamara Portfolio

A personal portfolio website showcasing my skills, projects, and services as a full-stack developer and AI integration engineer. The website is designed to provide potential clients and employers with an overview of my work and how to get in touch.

- [Technologies Used](#technologies-used)
- [Installation](#installation)
- [Usage](#usage)
- [Contact](#contact)

## Features
- **Responsive Design**: Fully responsive across desktop and mobile.
- **Interactive Navigation**: A sidebar (mobile) and top navigation menu (desktop) for easy access to different sections.
- **Sections**:
  - Home: Introduction and call-to-action buttons.
  - About: Information about me, my education, and interests.
  - Journey: Timeline of my professional development.
  - Experience: Overview of my professional skills and technical stack.
  - Projects: A selection of full-stack, AI, and blockchain work.
  - Certifications: Education and professional credentials.
  - Contact: A contact form for inquiries, with rate limiting and CAPTCHA protection.
- **Social & Contact Links**: GitHub, LinkedIn, X/Twitter, WhatsApp, Telegram, and Calendly.

## Technologies Used
- Next.js (App Router, Turbopack)
- React & TypeScript
- Resend (contact form email delivery)
- Cloudflare Turnstile (CAPTCHA)
- Font Awesome (self-hosted, for icons)
- Vercel (hosting and deployment)

## Installation
```bash
npm install
```

## Usage
```bash
npm run dev     # start the local dev server
npm run build   # production build
npm run lint    # lint the codebase
```
